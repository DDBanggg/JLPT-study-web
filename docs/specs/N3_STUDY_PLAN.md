## 1. Purpose

This document defines the learning architecture for the JLPT N3 phase after the N5/N4 transition block:

```text
Day 1–10 → N5/N4 normal review
Day 11   → Sprint 1 / N5-N4 closeout only
           - Daily Test 11 reviews Day 10
           - N4 End Test
Day 12   → N3 C1L1P1 learning + same-day Grammar Test + Reading + Listening
Day 13   → Daily Test 13 reviews C1L1P1, then N3 C1L1P2
```

The N3 plan is designed around four principles:

1. **Use one coherent curriculum backbone** so Grammar, Vocabulary and Kanji are learned in a consistent order.
2. **Do not rely on one source for coverage.** Use additional N3 lists/books as coverage-audit sources.
3. **Split each Gungun lesson across two Study Days** to keep the daily workload realistic.
4. **Use one week for one chapter** whenever possible, ending each week with a chapter-level test.

The original nine-week milestone structure remains in place, with the N3 foundation
starting cleanly after the N5/N4 closeout:

```text
C1L1P1 learning → Day 12
C1L1P1 Daily Test → Day 13
remaining core milestones → Day 13–74
```

After that, Day 75–100 remains available for gap filling, test practice, mock exams and final revision.

# 8. Core Rule — One Gungun Lesson = Two Study Days

A lesson must **not** be split by skill.

Bad split:

```text
Part A = Grammar + Vocabulary
Part B = Kanji + Reading
```

This creates uneven Study Days and weakens Daily Test semantics.

Instead, split every major learning domain across Part A and Part B.

Preferred model:

```text
Lesson X
├── Part A
│   ├── Grammar subset A
│   ├── Vocabulary subset A
│   ├── Kanji subset A
│   ├── Reading
│   └── Listening
└── Part B
    ├── Grammar subset B
    ├── Vocabulary subset B
    ├── Kanji subset B
    ├── Reading
    └── Listening
```

Each Study Day remains a complete learning day.

---

# 9. Part A / Part B Split Algorithm

The split must be deterministic and source-grounded.

## 9.1 Grammar split

For each Gungun lesson:

1. list all source grammar entries in source order;
2. group directly related variants when possible;
3. distribute approximately half to Part A and half to Part B;
4. do not split one semantic grammar family in a confusing way if it is designed to be compared together;
5. preserve source order unless semantic grouping requires otherwise.

Typical lesson:

```text
5–7 grammar entries
```

Typical split:

```text
Part A → 3–4
Part B → 2–4
```

No fixed quota should override sensible semantic grouping.

## 9.2 Vocabulary split

Gungun lessons commonly contain a relatively large vocabulary pool.

Recommended daily strategy:

```text
source lesson vocabulary
↓
split across A/B
↓
priority-rank each part
```

The existing Vocabulary runtime model remains locked:

```text
target = 50
pool <= 100
Active + Reserve semantics unchanged
```

N3 authoring remains source-driven. A typical actual source pool per Study Day may be:

```text
~30–40 eligible vocabulary items / Study Day
```

This range is descriptive, not a quota. If the source contains fewer than 50 eligible items, use all available items.

Mimikara 880 remains an audit/priority source only. Its overlap may receive a high priority signal, but it does not replace the Gungun lesson order.

Priority order:

```text
1. Gungun lesson core target
2. also appears in Mimikara 880
3. repeatedly used by Grammar/Kanji/Reading in the same chapter
4. high daily/JLPT usefulness
5. reusable across contexts
6. source order as tie-breaker
```

Avoid prioritizing:

```text
rare proper names
narrow specialist vocabulary
one-off examples
low-reuse items
```

When the source pool supports it, continue using the existing:

```text
Active
Reserve
```

Never import vocabulary from future lessons to reach 50.

## 9.3 Kanji split

Gungun Kanji order remains the daily learning order.

For each lesson:

```text
split source Kanji approximately 50/50
```

Typical source result:

```text
~6–8 Kanji / Study Day
```

The `~6–8` range is descriptive only. Kanji remains **source-exhaustive**:

```text
no ranking-based omission
no fixed quota
no future replacement
no reserve
```

All Kanji assigned to the lesson must eventually be taught across Part A + Part B.

Readings must come from source-taught usage.

Do not insert exhaustive dictionary readings.

Known Kanji are removed only. They are not replaced with future Kanji.

# 11. Grammar Test Rules

A same-day Grammar Test remains part of the Study Day architecture.

Purpose:

```text
immediate mastery check
```

It must test only Grammar learned on the current Study Day.

Preferred question style:

```text
JLPT-like 4-choice MCQ
fill-in-the-blank
particle / conjugation / grammar-form choice
```

Do not use:

```text
Vietnamese theory questions
"what does X mean?"
sentence-order ★ questions
long reading questions
```

Question quality rules:

```text
exactly 1 defensible answer
natural Japanese
plausible distractors
no future Grammar
no future Vocabulary used as required knowledge
```

### Question count — locked

```text
25 questions / normal learning Study Day
```

This keeps the existing Grammar Test architecture. Do not reduce the N3 Grammar Test to 15 questions.
